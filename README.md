# 정보통신 학습 노트

브라우저에서 사용하는 한국어 학습 사이트입니다. 정적 HTML 한 파일로 동작하며 별도 빌드 도구가 필요하지 않습니다.

## 기능
- 정보통신 핵심 이론 분류
- 분야별 객관식 예시 문제 풀이와 즉시 해설
- 오답 노트, 반복 오답 횟수, 다시 풀기
- 누적 풀이 수, 정답률, 과목별 정답률, 오늘의 목표
- 브라우저 localStorage 기반 학습 기록
- JSON 기록 내보내기 및 가져오기

## 실행
`index.html`을 브라우저에서 열면 됩니다.

## GitHub Pages 배포
1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Deploy from a branch**를 선택합니다.
3. Branch를 `main`, 폴더를 `/(root)`로 지정하고 Save를 누릅니다.
4. 배포 완료 후 저장소의 Pages URL에서 접속합니다.

## 주의
현재 문제는 기능 확인용 예시 8문제이며 공식 기출문제가 아닙니다. 기록은 사용 중인 브라우저에 저장되므로 다른 기기와 자동 동기화되지 않습니다. JSON 백업을 이용해 기록을 옮길 수 있습니다.
