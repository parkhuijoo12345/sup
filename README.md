# NETLAB — 네트워크관리사 2급 학습실

원본 프로젝트의 문제 데이터는 활용하되, 화면과 학습 흐름은 별도로 설계한 정적 웹 학습 사이트입니다. 원본 앱 코드를 복사하지 않고 새 HTML/CSS/JavaScript로 구현합니다.

## 현재 구현
- 원본 문제은행의 전체 문항 수와 회차를 자동 반영
- 회차별 연습 및 실전형 세션 시작
- 검색, 연도·회차·과목·풀이 상태 필터
- 원문 문제 이미지와 1~4번 선택지 표시
- 정답 확인, 이전·다음 이동, 문항 번호 이동
- 오답 복습, 북마크, 미풀이 우선 10문항
- 풀이 시도·정답률·학습일·세션 기록
- JSON 학습 기록 백업 및 복원
- PC·모바일 반응형 화면

## 데이터 출처
문제은행: https://github.com/sumilee-phd/NA2-study/blob/main/public/data/bank.json

문제은행은 원본 저장소의 main 브랜치에서 브라우저로 직접 불러옵니다. 따라서 첫 접속 시 큰 파일을 다운로드할 수 있고, 원본 저장소나 네트워크 상태에 따라 로딩에 영향을 받을 수 있습니다. 기록은 현재 브라우저의 localStorage에 저장됩니다.

## GitHub Pages 배포
저장소 Settings → Pages에서 Deploy from a branch, main, /(root)를 선택해 저장하세요. 이미 설정되어 있다면 커밋 후 자동 배포될 수 있습니다.

## 제한사항
- 원문 이미지 기반 문제 풀이이며, 원문에 별도 해설 텍스트가 없는 문항은 정답 번호만 표시합니다.
- 실기 자료, Windows·라우터 실습, 이론 강의는 아직 통합하지 않았습니다.
- 실전형 세션은 학습용이며 공식 시험 감독 기능이나 서버 동기화는 제공하지 않습니다.
- 학습 기록은 브라우저별로 별도입니다. 다른 기기로 옮길 때는 JSON 백업을 사용하세요.
